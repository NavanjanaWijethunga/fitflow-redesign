# fitflow-redesign
FitFlow redesign project for IT3060 Human Computer Interaction.
## Project Goal 

The goal of the redesign is to improve user retention and usability by addressing major problems identified in the FitFlow case study, including:

- Lack of personalized workout plans
- Social isolation and limited accountability
- Difficult nutrition tracking
- Reduced user motivation
- High friction during daily tracking

## Key Features 
- AI-powered personalized workout plans
- Social community and challenges
- Camera-based nutrition tracking - Progress tracking dashboard
- Personalized fitness recommendations

 
## Technology Stack 
- Frontend: React Native
- Backend: Node.js / NestJS
- Database: Firebase Cloud Firestore
- Authentication: Firebase Authentication
- AI/ML: TensorFlow Lite and ML Kit
- Optional AI Service: Python / FastAPI

## Project Structure 
- `frontend/` – Frontend application
- `backend/` – Backend services
- `ai-service/` – AI/ML services
- `docs/` – Project documentation
